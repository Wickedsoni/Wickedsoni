# Ping

My mascot: a living signal made of code brackets, with a HUD visor, a Wi-Fi antenna and a terminal cursor for a mouth.
Everything here is generated by [`scripts/build-ping.mjs`](../../scripts/build-ping.mjs). Edit that and run it to change Ping.

|:-:|:-:|:-:|:-:|:-:|

| `idle` | `wave` | `code` | `success` | `error` |

The poses are animated, have transparent backgrounds and work in light and dark mode.

## Use it in any repo

```html
<img src="https://raw.githubusercontent.com/Wickedsoni/Wickedsoni/main/assets/ping/ping-code.svg" alt="Ping" width="120" align="right">
```

Ideas: `code` on work-in-progress READMEs, `success` next to release notes, `error` on troubleshooting docs, `wave` on contributing guides.

## Images for GitHub settings

GitHub only accepts uploaded images in these places, so they're pre-rendered PNGs:

| File | Upload it at |
|---|---|
| [`png/avatar.png`](png/avatar.png) (1024×1024) | Profile → Settings → Public profile → Profile picture |
| [`png/social-<repo>.png`](png/) (1280×640) | Each repo → Settings → General → Social preview |
